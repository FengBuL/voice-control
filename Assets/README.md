# Voice icon

`VoiceIcon.png` is the app's source artwork. `scripts/build-icon.sh` generates the macOS `.icns` representations with `sips` and `iconutil`.

Generated with the built-in Imagegen tool. Design brief: a pearl-white rounded macOS tile with subtle glass depth, a cobalt-blue speaker and two sound waves, transparent surroundings, readable at small sizes, no text or brand marks.

The final prompt requested a single centered macOS volume app icon on a transparent square canvas with restrained native styling, crisp edges and a contained shadow. The source artwork is distributed under the repository's MIT license.

## Generation prompt

Use case: logo-brand. Create the finished application icon for a macOS menu bar volume app named Voice. Single centered icon, square 1024x1024 composition, isolated on a truly transparent background. macOS app icon styling: large rounded square tile occupying about 84% of canvas, soft continuous corners, pale pearl-white glass surface, very subtle cool blue edge lighting and gentle dimensional depth. On the tile place a bold simple three-dimensional cobalt-blue speaker glyph with two curved sound waves, clean recognizable silhouette, perfectly legible at 32px. Restrained premium native Mac aesthetic, soft studio light, crisp anti-aliased edges, slight contact shadow fully contained within the canvas. No microphone, no letters, no text, no Apple logo, no watermark, no device mockup, no surrounding scene. This is the actual reusable app icon artwork.
